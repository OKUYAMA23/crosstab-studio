CrossTab Studio 0.5.1　アンケートの集計と検定（R で計算する Windows 用ソフト）
==========================================================================

■ 起動のしかた
  1. このフォルダーを好きな場所に置きます。
  2. CrossTabStudio.bat をダブルクリックします。
     ・R が入っていないパソコンでは「このフォルダーの中に R を入れますか」と聞かれます。
       「はい」を選ぶと、R と必要な部品をこのフォルダーの中に入れます
       （初回のみ。インターネット接続が必要で、数分かかります）。
     ・R（4.2 以上）がすでに入っているパソコンでは、その R を使います。
       部品（httpuv、jsonlite）がなければ、初回の起動時に自動で入れます。
  3. すぐに起動画面（経過秒数と段階を表示）が開き、準備ができるとアプリの画面に替わります。
     窓を閉じると、裏で動いている R も数秒後に終了します。

  デスクトップにショートカットを作る
    make_shortcut.bat をダブルクリックすると、デスクトップ・スタートメニュー・このフォルダーに、アイコン付きの
    「CrossTab Studio」を作ります（このフォルダーのものは好きな場所へ移して使えます）。ショートカットから起動すると、黒いコマンドの窓は出ません。
    このフォルダーを移したときは、もう一度実行してください。

  うまく起動しないとき
    CrossTabStudio_debug.bat   … 経過を表示しながら起動します。startup.log（R の記録）と launch.log（起動の記録）が残ります。
    CrossTabStudio_browser.bat … アプリ用の窓ではなく、ふだんのブラウザのタブで開きます。
    setup_R.bat                … R と部品を入れる作業だけを行います。

■ 保存
  タイトルバーの「上書き保存」（Ctrl+S）で、データと設定をまとめてアプリの中に保存します。未保存の変更があるときは青くなります。
  その左の「自動保存」をオンにすると、変更するたびに数秒後に自動で上書き保存します（最初に名前を付けます）。

■ 使い方（作業の順番）
  1. CSV を入れる　　　回答の CSV（Google スプレッドシートの「ファイル → ダウンロード → カンマ区切り形式」）を画面にドロップ。
  2. 解析を始める　　　「解析を始める」（2 つ目からは「新しい解析」）で種類を選ぶと、1 つの画面の下へ順に並びます（最大 20 個）。
                        見出しの ∨ で畳めます。有意な解析は、畳んでいても名前が赤い太字になります。
                        名前の変更は見出しを右クリック →「名前を変更」（または F2）。並べ替えは見出しをドラッグ、または ▲▼。
  3. 設問を選ぶ　　　　解析の欄の中で設問を選ぶと、すぐに p 値・表・図・報告書の文が出ます（表が上、図が下）。
                        同じ設問を 2 つの欄に選ぶと、エラーを表示します。選択肢のまとめ方・除外・絞り込みは右の作業ウィンドウで設定します。
  4. 図と表を整える　　図や表をクリックすると「図」「表」タブに切り替わります。
                        図：種類（帯グラフ・集合棒・積み上げ棒・色分けの表・棒グラフ・円グラフ・箱ひげ図・散布図）、凡例（位置・形・枠。図の上でドラッグしても動かせます）、目盛り（向き・目盛線・軸）、
                            配色（濃淡・2 方向・多色・白黒の模様）、
                            凡例の背景の色（透明も可）、凡例の名前の変更（作業ウィンドウ、または凡例の名前をダブルクリック）、
                            値のラベル（割合・人数・両方。円グラフでも同じ）、
                            書体、文字の大きさ、線の太さ、背景の透過。右端・下端・右下の角をドラッグすると大きさが変わります。
                            1 つの解析に図を複数置けます（図 1、図 2 …）。
                        表：デザイン（格子・三線・縞・線なし・見出し塗り）、書体、線の種類と色、セルの色分けとカラーバー。
  5. まとめて書き出す　☑ を付けた解析について、次の 3 種類を、選んだフォルダーに書き出します。
                        ・図　　　「解析の名前_図1.png」（解析ごとに 1 から番号。画面に出ている形と大きさのまま）
                        ・Excel　 CSV をシートにし、その右側（1 列あけた先）に Excel の関数で解析を再現（値の貼り付けなし）
                        ・報告書　すべての解析の文と表を 1 つのテキストに

■ 設問の名前
  設問の名前は省略せずに表示します。表形式の質問は「Q8 最近1か月、孤独だと感じる。」のように番号と項目で表し、
  項目が短いとき（サービス名など）は問いの最初の文を（ ）で添えます。表示名は「データ」で書き換えられますが、
  報告書の文には書き換え前の省略しない名前を使います。

■ プロジェクトの保存
  「上書き保存」で、データ（CSV の中身）・解析・図と表の設定を 1 つのプロジェクトとして、
  このフォルダーの projects に保存します。次からは「プロジェクトを開く」（または起動直後の一覧）で、CSV なしで開けます。
  別のパソコンに移すときは「書き出し」→「ファイルに書き出す」で .prj を作り、相手の画面にドロップします。

■ できる解析
  単純集計（適合度の検定つき）、複数の設問の単純集計（同じ選択肢の設問を並べる。フリードマン検定つき）、カイ二乗検定、フィッシャーの正確確率検定、割合の傾向検定（コクラン・アーミテージ）、
  マン・ホイットニーの U 検定、クラスカル・ウォリス検定（多重比較つき）、スピアマンの順位相関、
  複数回答のクロス集計、ウィルコクソンの符号付順位検定、マクネマー検定

■ Excel ファイルについて
  2×2 より大きい表のフィッシャーの正確確率検定と、クラスカル・ウォリス検定のあとの多重比較は、
  Excel の関数では再現できないため、数式を載せていません（その旨をシートに書きます）。
  Excel 2010 以降の関数（CHISQ.DIST.RT、HYPGEOM.DIST、RANK.AVG など）を使います。

■ フォルダーの中身
  CrossTabStudio.bat ほか   起動用のファイル
  tools\                    起動と初回の準備のスクリプト（PowerShell）
  app\run.R                 起動する R スクリプト
  app\R\                    計算の本体（data.R：読み込みと列の種類の判定、stats.R：共通の部品、analyses.R：解析の登録簿と定型文、
                            excel.R：Excel の数式の生成、server.R：画面との通信）
  app\www\                  画面（HTML・CSS・JavaScript）
  projects\                 保存したプロジェクト（保存すると作られます）
  R\、app\library\         初回の準備で作られます（R の本体と部品）

■ 動作の条件
  Windows 10 / 11、Microsoft Edge または Google Chrome。データはこのパソコンの中だけで処理し、外部に送信しません。
